# ejcp2026

This repo contains the contents of the Compiler day on for the École des jeunes chercheuses et jeunes chercheurs en Sciences du Logiciel (EJCP) 2026, organized in Nantes.

https://ejcp2026-scilog.ls2n.fr/

## Agenda

9h-10h30 : Theory — Introduction to compilation and language implementations.

11h-12h30 : Lab — exploring generated code in different languages

14h-15h30 : Theory — Compiler testing and Fuzzing

16h-17h30 : Lab — Fuzzing a buggy parser

## Repo Organization

- The `Modules` folder contains the theory slides
- The `Practice` folder contains the lab exercises
